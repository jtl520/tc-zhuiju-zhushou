# 天虫视频助手

主脚本为 `zhuiju.txt`，当前版本 **2.0.8**。将完整内容复制到 Tampermonkey（油猴）的脚本编辑器中保存，再刷新网页。

主要功能：片名与集数识别、酷播目标站搜索、视频倍速、画中画、定时暂停和网页分页跳转。

## 网页跳页

1. 打开网页，点击悬浮毛毛虫。
2. 在主面板下方的“网页跳页”输入目标页码，点击“跳转”或按 Enter。
3. 网页分页延迟加载时，点击“识别”重新检测；存在多个分页区域时可选择对应区域。

脚本优先点击网页已有的页码控件，随后尝试根据至少两个页码链接推导地址，或调用网站原生跳页框。支持路径分页、查询参数、hash 路由，以及链接中能推导出步长的 `offset`、`start`、`pn` 等偏移量分页。跳转保留链接里的搜索词、排序和其他参数。只有明确识别出总页数时才限制上限，不会把当前显示的最大页码当作末页。

没有分页组件时，可识别当前 URL 中单个明确的正整数页码参数（如 `page=2`）；这种回退按从 1 开始计数处理。零基页码和偏移量需要网页链接提供额外证据。仅提供按钮但没有地址规则的网站，可点击已显示的页码，或尝试使用原生跳页框。

无限滚动、游标分页、受保护的 iframe 内分页，以及拒绝模拟事件的组件，可能无法直接访问任意页码；脚本会提示无法识别，不会连续点击数百次“下一页”。分页识别仅在打开面板、点击识别或提交时执行。

必应搜索的 `first` 偏移量会受动态每页条数影响，不能稳定换算成远处页码，因此仅支持直接点击当前已显示的页码，不推算未显示页。Google 等有一致分页链接的搜索结果可推导跳转；搜索引擎自身的结果上限仍然有效。

## 验证

运行 `node tests/pagination.test.cjs` 检查地址推导与浏览器交互。测试使用 Node 内置模块，不需要安装依赖；浏览器测试使用本机 Chrome 或 Edge，也可通过 `TC_TEST_BROWSER` 环境变量指定可执行文件路径。

2026-11-06 验证：22 项地址／语法检查、18 项完整脚本浏览器交互检查通过。另读取真实网站的分页链接并验证目标页面：Google 第 12 页、GitHub Issues 第 12 页、Hacker News 第 5 页；必应已显示的第 6 页可直接访问，但远页推算实测不稳定，已禁用。实站目标地址验证与本地脚本交互测试分别进行，不等同于在全部网站安装新版本后的完整回归。
